# Learning C++ - OOP Project Collection

This repository is organized as **one project per Git branch** based on the Spring 2026 Object-Oriented Programming project collection.

`main` is intentionally only an index/base branch. Each implementation lives on its own `project-XX-...` branch and is independently buildable with CMake and a C++17 compiler.
